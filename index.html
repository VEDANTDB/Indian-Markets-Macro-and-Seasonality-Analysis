Method and data notes

1. Regime detection

Each indicator is converted to a z-score: (reading − centre) ÷ scale, with the yield slope inverted. G = 0.35 credit + 0.25 PMI + 0.20 IIP + 0.20 earnings revisions. I = 0.35 CPI + 0.30 repo change + 0.20 Brent momentum + 0.15 inverted yield slope. Regime 1: G ≥ 0 and I < 0. Regime 2: G > 0 and I ≥ 0. Regime 3: G ≤ 0 and I > 0. Regime 4: G < 0 and I ≤ 0.

2. Allocation

Regime weights and expected returns come from the report's dynamic allocation matrix. The long-term risk-parity column is shown for reference. The report's optimiser uses Black-Litterman views, Hierarchical Risk Parity and a quadratic solver with 2–25% sector caps, a 4.5% tracking-error limit and a 30% quarterly turnover cap. This dashboard shows the target weights; it does not run the optimiser.

3. Signals and seasonality

The signal score combines regime-relative weight and the month's seasonal score. Seasonal scores and win rates come from the report's monthly tables, which the report presents without a sample period. Treat them as context, not timing signals.

4. Source data checks

The report's regime weight columns do not sum to 100 (the checks show each total; normalisation is on by default). Regime 1 lists Banks at 30%, above the report's 25% cap. The FMCG FX elasticity (+0.39) looks misaligned with its sector and is flagged for review. Mid-cycle favoured sectors were corrected in this version to Infra / capital goods and IT, matching the report's text; Banks had been added in error.

5. Market context

This dashboard does not pull live rates. Enter the current repo rate, CPI and other readings yourself, and check the latest RBI decision before relying on the repo input. The repo presets are illustrative, not live readings.

Glossary

Z-score: distance from a normal level in standard deviations. Repo: RBI's policy rate. EBLR: external benchmark lending rate, to which floating retail loans are linked. IIP: industrial production index. PMI: purchasing managers' index (50 = no change). Active share: portion of the portfolio that differs from the index. Sharpe: return above risk-free per unit of volatility. TREPS: overnight cash instrument.

Research tool, not investment advice. Figures come from the two source reports and the readings you enter.
